# 📝 Smart Notes AI

Sebuah aplikasi pencatatan pintar berbasis web yang dibangun menggunakan **Laravel**.

## ✨ Fitur Utama

- **Autentikasi:** Sistem login dan register pengguna.
- **Manajemen Catatan:** Membuat, membaca, mengubah, dan menghapus catatan (CRUD).
- **Mode Gelap (Dark Mode):** Tampilan antarmuka yang nyaman di mata menggunakan Tailwind CSS.
- **Kuis:** (Penjelasan fitur kuis kamu di sini...)

## 🛠️ Teknologi yang Digunakan

- Laravel
- Tailwind CSS
- MySQL

## 🚀 Cara Menjalankan Proyek Secara Lokal

1. Clone repository ini.
2. Jalankan perintah `composer install`.
3. Jalankan perintah `npm install` dan `npm run dev`.
4. Copy file `.env.example` menjadi `.env` lalu generate key dengan `php artisan key:generate`.
5. Buka melalui Laravel Herd atau jalankan `php artisan serve`.
